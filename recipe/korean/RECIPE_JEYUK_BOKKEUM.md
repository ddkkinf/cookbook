# 🥩 불맛 가득 기사식당 스타일 제육볶음 레시피

고기를 양념에 미리 재우지 않고, 팬에서 노릇하게 먼저 구운 뒤 설탕·간장으로 불맛을 입혀 물기 없이 볶아내는 텁텁함 제로 황금 레시피입니다.

---

## 📌 개요
집에서 제육볶음을 할 때 흔히 생기는 '한강물(흥건한 국물)'과 고추장의 텁텁함을 완벽하게 잡은 백반집·기사식당 스타일 레시피입니다.

* **핵심 포인트:** 고기를 먼저 구워 수분 날리기, 설탕 먼저 넣어 윤기·불맛 코팅하기, 고추장은 줄이고 고춧가루·간장 비율 높이기
* **조리 분량:** 2인분 기준
* **조리 시간:** 약 15분
* **난이도:** 쉬움
* **검증 상태:** 미검증
* **코멘트:** 
* **분류:** 한식

## 🛒 재료 (2인분 · 고기 300g 기준)

> [!NOTE]
> **계량 기준:** 1큰술(1T) = 계량스푼 15ml 기준입니다. 저울 사용 시 함께 표기된 **그램(g)** 단위를 참고하세요.

### 1. 주재료 및 채소
| 재료 | 수량 / 분량 (g·ml) | 손질 및 비고 |
| :--- | :--- | :--- |
| **돼지고기 (앞다리살 또는 삼겹살)** | 300g | 불고기용(얇은 두께 3~4mm) 한 입 크기 |
| **양파** | 1/2개 (약 100g) | 0.5cm 두께로 도톰하게 채 썰기 |
| **대파** | 1대 (약 40~50g) | 큼직하게 어슷썰기 (또는 반 갈라 4cm 토막) |
| **청양고추 (선택)** | 1~2개 (약 15g) | 어슷썰기 *(매콤한 칼칼함 추가)* |
| **식용유** | 1큰술 (약 15ml) | 앞다리살일 때 사용 *(삼겹살은 생략 가능)* |
| **참기름 & 통깨** | 1큰술 (10g) / 약간 | 불 끄고 마지막 마무리용 |

### 2. 양념 재료 (큰술 & 그램 병기)
| 재료 | 수량 / 분량 (g·ml) | 비고 |
| :--- | :--- | :--- |
| **설탕 (고기에 먼저 투입)** | 1큰술 (약 10~12g) | 고기 연육 및 카라멜라이징(불맛 코팅) |
| **진간장 (팬 가장자리에 투입)** | 2큰술 (약 30g / 30ml) | 태우듯 끓여 깊은 불향과 감칠맛 생성 |
| **맛술 (미림)** | 1큰술 (약 15g / 15ml) | 돼지고기 잡내 제거 |
| **고춧가루** | 2큰술 (약 14~16g) | 깔끔하고 칼칼한 붉은 색감의 핵심 |
| **고추장** | 1큰술 (약 20g) | 깎아서 1큰술 *(많이 넣으면 텁텁해짐)* |
| **굴소스** | 0.5큰술 (약 7~8g) | 기사식당 특유의 감칠맛 비법 *(생략 시 간장 0.5T 추가)* |
| **다진 마늘** | 1큰술 (약 15g) | 풍미 상승 |
| **물엿 (또는 올리고당)** | 1큰술 (약 15~20g) | 매콤달콤한 밸런스와 윤기 |
| **후춧가루** | 약간 (3~4번 톡톡) | 잡내 제거 및 알싸한 향 |
| **물** | 2~3큰술 (약 30~45ml) | 양념이 타지 않고 고기에 착 감기게 하는 촉촉함 |

## 🍳 조리 순서 (Instructions)

### Step 1. 채소 손질 및 양념장 미리 섞기
1. **채소 썰기:** 양파(1/2개, 100g)는 볶았을 때 식감이 살아있도록 도톰하게 채 썰고, 대파(1대)와 청양고추는 어슷썰어 준비합니다.
2. **고기 손질:** 돼지고기(300g)는 핏물을 키친타올로 가볍게 닦고 먹기 좋은 한 입 크기(4~5cm)로 썰어둡니다.
3. **붉은 양념장 배합:** 먼저 넣을 **설탕·진간장을 제외한** 나머지 양념을 작은 그릇에 미리 섞어둡니다.
   * 고춧가루 **2큰술 (15g)** + 고추장 **1큰술 (20g)** + 굴소스 **0.5큰술 (7g)**
   * 다진 마늘 **1큰술 (15g)** + 맛술 **1큰술 (15g)** + 물엿 **1큰술 (15~20g)** + 물 **2~3큰술 (30~45ml)** + 후추 약간

### Step 2. 돼지고기 먼저 노릇하게 굽기 (수분 날리기)
1. **강불 고기 굽기:** 넓고 달군 팬에 식용유 1큰술을 두르고 **강불**에서 돼지고기를 넓게 펼쳐 올립니다.
2. **수분 증발:** 고기에서 나오는 하얀 육수가 다 날아가고 고기 겉면이 **노릇노릇하게 구워질 때까지** 충분히 볶아줍니다.
   *(삼겹살처럼 기름이 너무 많이 나왔다면 키친타올로 기름을 절반 정도만 살짝 닦아내세요.)*

### Step 3. 설탕 코팅 & 간장 불맛 입히기 (핵심 비법!)
1. **설탕 먼저 볶기:** 노릇하게 익은 고기 위에 **설탕 1큰술(10~12g)**을 골고루 뿌리고 **강불에서 30초간** 볶아 고기 표면에 쫀득한 윤기와 불맛 코팅을 입힙니다.
2. **간장 태우듯 넣기:** 고기를 팬 한쪽으로 밀어 빈 공간을 만든 뒤, **진간장 2큰술(30g)**을 팬 바닥에 떨어뜨립니다.
3. **불향 입히기:** 간장이 바글바글 끓으며 구수한 불향이 올라오면(약 5~10초) 고기와 빠르게 섞어 볶아줍니다.

### Step 4. 양념장과 채소 넣고 강불에 빠르게 볶기
1. **양념장 투입:** 불을 **중불**로 잠시 줄이고(타지 않게), 미리 섞어둔 **붉은 양념장**을 넣어 고기에 양념이 고루 배도록 1분간 볶습니다.
2. **채소 투입 후 강불:** 손질한 **양파, 대파, 청양고추**를 모두 넣고 다시 **강불**로 올립니다.
3. **빠르게 마무리:** 양파가 아삭하게 반쯤 익을 정도로만 **1분 30초~2분간 빠르게 볶아낸 뒤** 불을 끕니다. *(오래 볶으면 채소에서 물이 나와 질척해집니다.)*
4. **참기름·통깨:** 불을 끈 상태에서 **참기름 1큰술(10g)**과 **통깨**를 둘러 가볍게 뒤적여 완성합니다.

## 💡 요리 팁 & 더 맛있게 먹는 법 (Tips)

* **고기 부위 추천:** 기름기가 적당하고 부드러운 **앞다리살(전지)**이 가성비와 식감 모두 가장 좋으며, 고소한 기름 맛을 좋아하시면 **얇은 삼겹살**이나 **목살**을 섞어 쓰셔도 훌륭합니다.
* **쌈채소 & 계란후라이:** 상추·깻잎 쌈에 마늘 한 점 올려 싸 먹거나, 대접에 밥과 반숙 계란후라이, 김가루를 얹어 **제육덮밥**으로 비벼 먹어도 최고입니다!
