# 👨‍💻🍳 개발자의레시피 · Developer's Recipe (Web & Android Hybrid App)

GitHub Markdown 기반의 **스마트 레시피 웹 & 안드로이드 하이브리드 앱**입니다.  
`/recipe` 폴더 하위에 마크다운(`.md`) 파일로 새 레시피를 추가하면 **웹페이지**와 **안드로이드 앱** 모두에 실시간으로 자동 반영됩니다!

* 🌐 **웹사이트:** [https://ddkkinf.github.io/cookbook/](https://ddkkinf.github.io/cookbook/)
* 📲 **안드로이드 앱(APK) 최신 다운로드:** [kim-cookbook.apk 바로 받기](https://github.com/ddkkinf/cookbook/releases/latest/download/kim-cookbook.apk)

---

## ✨ 주요 기능

1. **⚖️ 인분 조절 & 스마트 양념 비율 자동 보정**
   - 각 레시피의 기본 인분(1~2인분)을 기준으로 `0.5인분 ~ 20인분`까지 자유롭게 변경 가능
   - 단순 `n배` 정배수가 아니라 요리 원리에 맞춰 재료 역할별로 자동 보정:
     - **주재료 (고기·생선·떡·밥·채소):** 인분에 맞춰 정비례(`n배`) 계산
     - **고염도 양념 (소금·간장·고추장·굴소스·다시다):** 다인분 조리 시 염도 누적으로 짜지는 현상 방지 (`r^0.85` 감쇠 보정)
     - **보조 양념 (설탕·물엿·맛술·마늘·참기름):** 단맛·향 과다 방지 밸런스 보정 (`r^0.90`)
     - **팬 코팅 기름 (식용유·버터):** 팬 바닥 면적을 고려해 과다 투입 방지 (`45%` 완만 증가)
     - **국물·육수 (물 100ml 이상):** 냄비 증발량 차이를 반영해 한강 방지 (`80%` 비례)
2. **⏱️ 단계별 원터치 조리 타이머 (멀티 타이머 지원)**
   - 조리 순서 본문에서 `3분`, `1분 30초`, `30초` 등 시간이 필요한 구간을 자동 인식해 **타이머 시작 버튼** 제공
   - 여러 개의 타이머 동시 실행, `+30초 / +1분` 연장, 완료 시 **디지털 주방 알람음 + 진동** 알림
   - 조리 중 손에 물이나 양념이 묻어도 화면이 꺼지지 않는 **🔆 화면 켜짐 유지(WakeLock)** 지원
3. **🎛️ 인터랙티브 베리에이션 & 밀프렙 모드 전환**
   - 레시피 상세 화면에서 **모드 전환**(예: 크림파스타 → 투움바/바질, 떡볶이·제육볶음 → 소스만 미리 만들기 / 양념육 숙성) 및 **취향 옵션 토글**(예: 떡볶이 라면사리 추가, 김치볶음밥 참치·계란후라이·햄 선택) 지원
   - 선택한 베리에이션에 맞춰 필요 재료(인분 자동 계산 연동)와 조리 순서·타이머가 즉시 변경됨
4. **🕘 스마트 최근 조회 최상단 정렬 (30초 필터)**
   - 마지막에 조회한 레시피가 목록 맨 위로 자동 정렬되며, 실수로 잘못 터치한 레시피가 올라오지 않도록 **최소 30초 이상 화면을 본 경우에만** 최근 조회로 반영
5. **📦 오프라인 기본 레시피 내장 + GitHub 실시간 동기화**
   - 앱 빌드 시점의 모든 레시피가 APK 내부에 기본 내장되어 비행기 모드/오프라인에서도 즉시 열람 가능
   - 인터넷 연결 시 GitHub 저장소의 신규/수정 레시피를 자동으로 백그라운드 동기화 및 기기 캐싱

## 📂 디렉토리 구조

```text
cookbook/
├── .github/workflows/
│   └── build-apk.yml           # GitHub Actions 안드로이드 APK 자동 빌드 & 릴리스 배포
├── android/                    # Capacitor 안드로이드 네이티브 프로젝트
├── docs/                       # 웹앱 소스 및 GitHub Pages 배포 디렉토리
│   ├── index.html              # 메인 앱 (인분 계산기 · 베리에이션 · 멀티 타이머 · 최근 조회 정렬)
│   ├── bundled-recipes.js      # 오프라인 내장용 레시피 번들 (자동 생성)
│   └── vendor/marked.min.js    # 오프라인용 마크다운 파서
├── recipe/                     # 레시피 마크다운 원본 모음
│   ├── korean/                 # 한식 카테고리 (떡볶이, 김치볶음밥, 제육볶음, 간장계란밥, 갈치·고등어구이)
│   ├── japanese/               # 일식 카테고리 (부타동)
│   └── western/                # 양식 카테고리 (크림파스타 · 투움바 · 바질)
└── scripts/
    └── bundle-recipes.mjs      # recipe/**/*.md -> docs/bundled-recipes.js 번들 스크립트
```

---

## 🛠️ 로컬 개발 & 빌드 명령어

```bash
# 마크다운 레시피를 오프라인 번들(docs/bundled-recipes.js)로 갱신 및 Android 프로젝트 동기화
npm run sync
```
